# حصة البرميل — Demo

ديمو عربي بسيط لإدارة عروض الشحن من السعودية إلى ود مدني بدون قاعدة بيانات أو Backend.

## الفكرة

1. تدخل بيانات العميل.
2. تدخل عدد الحصص التي يريدها العميل؛ العدد غير مقيد بقائمة ثابتة.
3. تدخل حتى 3 منتجات مع سعر السعودية، سعر السودان، الكمية، والروابط.
4. التطبيق يحسب سعة الطلب والتكلفة واصل مدني ونسبة التوفير.
5. يعطي قرارًا بسيطًا: مناسب / توفير ضعيف / غير مناسب.
6. يولد رسالة واتساب جاهزة للنسخ أو الفتح مباشرة في واتساب.
7. تحفظ العرض محليًا وتسترجعه لاحقًا.
8. تصدّر كامل السجل إلى Excel أو تستورده مرة أخرى.

## الإعداد الافتراضي الحالي

- البرميل: 220 لتر / 100 كجم.
- مساحة بضاعتك: 20 كجم / 50 لتر.
- احتياط: 5 كجم / 20 لتر.
- عدد الحصص في البرميل ديناميكي، والافتراضي: 2.
- سعة الحصة تُحسب تلقائيًا من المساحة المتاحة ÷ عدد الحصص.
- أمثلة بالإعدادات الحالية: 2 حصص = 37.5 كجم / 75 لتر، 3 = 25 كجم / 50 لتر، 5 = 15 كجم / 30 لتر.
- شحن البرميل: 500 ريال.
- بيع البرميل المتوقع: 100 ريال.
- هامش أمان: 50 ريال.
- سعر الحصة المقترح يُحسب تلقائيًا: `(الشحن - بيع البرميل + هامش الأمان) ÷ عدد الحصص`.
- مع حصتين: 225 ريال، مع 3 حصص: 150 ريال، مع 5 حصص: 90 ريال.
- يمكن تعطيل التحديث التلقائي وإدخال سعر حصة يدوي.
- حد الجدوى: توفير 15% فأكثر.

كل القيم قابلة للتعديل من شاشة الإعدادات، ويمكن للعميل حجز عدد حصص أكبر من تقسيم البرميل؛ التطبيق يحسب عدد البراميل المطلوبة تلقائيًا.

## Excel بدل قاعدة البيانات

الموقع Static، لذلك لا يمكنه تعديل ملف Excel الموجود داخل GitHub تلقائيًا بدون Backend أو صلاحية كتابة. لهذا الديمو يستخدم:

- `localStorage` للعمل السريع داخل المتصفح.
- Excel للاستيراد/التصدير والنسخة الرئيسية/الاحتياطية.
- ملف `data/barrel-share-data.xlsx` كقالب جاهز.

بيانات العملاء لا تُرفع إلى GitHub تلقائيًا.

## التشغيل

افتح `index.html` مباشرة، أو شغّل أي Static Server، أو انشر الملفات عبر GitHub Pages.

## هيكل Excel

- `Settings`: إعدادات البرميل والحساب.
- `Customers`: بيانات العملاء والمستلمين.
- `Quotes`: ملخص كل عرض ونتيجة الجدوى.
- `Products`: تفاصيل المنتجات والروابط والأسعار.
- `Dashboard`: مؤشرات تشغيل مختصرة.
